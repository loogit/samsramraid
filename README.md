# The Altman Utilization Audit

Next.js (App Router) parody site. No database, no tracking, no env vars required.

## Deploy
1. `npm i && npm run dev` to preview.
2. Push to GitHub, import the repo at vercel.com/new (framework auto-detected).
3. Buy your domain in Vercel, add it under Project > Domains.
4. Set `NEXT_PUBLIC_SITE_URL=https://yourdomain.com` in Project > Environment Variables, then redeploy. This drives canonical URLs, the sitemap and share-card images.

## Before you launch
- Add links to primary sources (Tom's Hardware, Gizmodo, the Cheeky Pint episode) in the "What actually happened" section. Verify every claim yourself; the copy is based on press coverage you pasted.
- Submit the sitemap in Google Search Console and Bing Webmaster Tools.
- Test a share link at /?ram=128&n=YourName in the X card validator and Discord to confirm the warrant image renders.
